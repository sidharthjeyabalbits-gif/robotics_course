Home / Curriculum
📚 12 Modules · ~14 weeks

The full course, module by module

From Linux and Python fundamentals through ROS2, sensing, object detection, and the complete Nav2 navigation stack — ending in a capstone autonomous robot you build yourself. Click any module to expand it.

01

Foundations — The Robotics & AI Landscape

Week 1 · Theory + math refresher
+

A grounding in what makes a robot "autonomous": the sense–plan–act loop, and the math you'll lean on for the rest of the course.

  • What is a robot? Sense–Plan–Act loop
  • Coordinate frames & transforms (2D/3D)
  • Linear algebra refresher: vectors, rotation matrices
  • Probability basics for sensor noise
  • Where AI fits: perception vs. planning vs. control
  • Course roadmap & the capstone robot preview
CoreMathConcepts
02

Linux, Git & Python for Robotics

Week 2 · Tooling
+

The everyday tooling every ROS2 developer needs before writing a single node.

  • Ubuntu & shell essentials (bash, permissions, processes)
  • Git & GitHub workflow for robotics projects
  • Python for robotics: classes, threading basics, NumPy
  • Virtual environments & dependency management
  • SSH & remote development on a Raspberry Pi
  • Debugging tools: htop, journalctl, tmux
CoreLinuxPython
03

ROS2 Basics

Weeks 3–4 · Core framework
+

The ROS2 mental model: how independent nodes talk to each other, and the tools to inspect that traffic live.

  • Nodes, topics, publishers & subscribers
  • Services vs. actions — when to use each
  • Packages, workspaces & colcon build
  • Launch files & parameters (YAML)
  • tf2: transforms between frames
  • rviz2 & rqt for visualization and debugging
  • Writing your first Python (rclpy) node
CoreROS2rclpy
🔗

Try it live: jump to the ROS2 Data Flow Visualizer lab to see nodes and topics animate through a real navigation pipeline.

04

Robot Kinematics & Differential Drive

Week 5 · Motion fundamentals
+

How two independently driven wheels turn into a robot's linear and angular velocity — and how to keep track of where the robot actually is.

  • Differential drive kinematics: v, ω from wheel speeds
  • Wheel encoders & odometry integration
  • IMU basics & sensor fusion (complementary/Kalman intro)
  • PID control for wheel velocity
  • Publishing /odom and the odom → base_link transform
  • Common drivetrain mistakes and how to avoid them
CoreKinematicsPID
🕹️

Try it live: steer a virtual robot in the Differential Drive Simulator, then tune a loop in the PID Playground.

05

Sensors & Perception

Week 6 · Reading the world
+

The sensor suite that turns a blind chassis into a robot that understands its surroundings.

  • 2D LiDAR: sensor_msgs/LaserScan
  • Cameras: intrinsics, calibration, image topics
  • Ultrasonic & IR proximity sensors
  • IMU: accelerometer, gyroscope, magnetometer
  • Sensor fusion basics for a mobile base
  • Noise, drift, and how to sanity-check sensor data
CoreLiDARCameraIMU
06

Computer Vision & Object Detection Models

Weeks 7–8 · AI perception
+

From classic image processing to real-time neural object detectors running on-device.

  • OpenCV fundamentals: filtering, contours, color thresholds
  • CNNs in 20 minutes: convolution, pooling, feature maps
  • Object detection models: YOLO family, SSD, MobileNet-SSD
  • Evaluating detectors: IoU, precision/recall, NMS
  • Model optimization: quantization, ONNX, TensorRT
  • Deploying a detector on Raspberry Pi / Jetson inside ROS2
  • Publishing detections as vision_msgs
CoreOpenCVYOLOEdge AI
📦

Try it live: drag boxes and watch scoring change in the IoU Playground — the exact metric used to grade detectors like YOLO.

07

The Navigation Stack — Costmaps & Global Planner

Week 9 · Nav2 part 1
+

How Nav2 turns a map and a goal pose into a safe path across the environment.

  • Nav2 architecture overview: servers & lifecycle nodes
  • Costmap2D: static, obstacle, and inflation layers
  • Global planners: Dijkstra, A*, NavFn, Smac Planner
  • Heuristics & grid vs. graph-based planning
  • Global vs. local planning — why you need both
  • Configuring planner plugins via YAML
CoreNav2A*Costmaps
🧭

Try it live: draw your own maze and race A* to the goal in the Global Planner Visualizer.

08

Local Planner & Controllers

Week 10 · Nav2 part 2
+

Turning a global path into safe, real-time velocity commands that react to obstacles the map didn't know about.

  • Local planners: DWA (Dynamic Window Approach), TEB
  • Trajectory scoring: obstacle cost, path alignment, speed
  • Controllers: Regulated Pure Pursuit, velocity smoothing
  • Publishing /cmd_vel and closing the control loop
  • Recovery behaviors: spin, back-up, clear costmap
  • Tuning for a small differential-drive base
CoreDWAControllers
🛑

Try it live: place obstacles and watch a reactive planner steer around them in the Local Planner Lab.

09

SLAM & Localization

Week 11 · Mapping the world
+

Building a map from scratch, and figuring out where your robot is inside one it already has.

  • Mapping vs. localization — the two halves of SLAM
  • slam_toolbox for 2D LiDAR mapping
  • AMCL: particle-filter localization on a known map
  • Saving & loading maps (map_server)
  • Loop closure & drift correction, briefly
  • When to remap vs. relocalize
CoreSLAMAMCL
10

Behavior Trees & System Integration

Week 12 · Tying it together
+

How Nav2 sequences planning, recovery, and detection into one coherent autonomous behavior.

  • BT Navigator & behavior tree basics
  • Composing custom behavior trees (XML)
  • Multi-node system architecture for a full robot stack
  • Combining navigation with object detection (e.g. "patrol & report")
  • Logging, diagnostics, and ros2 bag for debugging
CoreBehavior TreesIntegration
11

DIY Robot Build — From Simulation to Hardware

Week 13 · Hands-on build
+

Everything from modules 1–10, now applied to real hardware costing under ₹50,000.

  • Chassis assembly & motor wiring
  • Flashing & configuring the Raspberry Pi
  • Bringing up ROS2 drivers for motors, LiDAR & camera
  • Calibrating odometry on real hardware
  • Running Nav2 + SLAM on the physical robot
  • Safety: e-stops, current limits, battery care
CoreHardwareBudget build
🔧

Full guide: see the DIY Robot Build page for the complete bill of materials, wiring, and step-by-step assembly.

12

Capstone Project — Autonomous Patrol Robot

Week 14 · Demo day
+

Bring every module together into one demo: a robot that maps a room, localizes itself, navigates to waypoints, and reports what it sees.

  • Define a mission: patrol route + object-of-interest detection
  • Integrate SLAM, Nav2, and your object detector
  • Handle edge cases: dynamic obstacles, lost localization
  • Record a demo run with ros2 bag
  • Present & document your build
CoreCapstoneDemo
