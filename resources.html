🛒 Sourcing hardware

Where to find DIY build parts

Prices in the Bill of Materials assume typical hobbyist-electronics retail pricing in India. Compare a few sellers before buying — LiDAR and battery prices in particular vary a lot.

🏬

Local electronics markets

Often the cheapest source for chassis kits, motors, drivers, and passive components — and you can inspect quality before buying.

📦

Hobbyist robotics retailers

Specialty Indian robotics/electronics stores stock RPLidar units, IMUs, and Raspberry Pi boards with local warranty support.

♻️

Reuse & secondhand

A spare Raspberry Pi, an old webcam, or a salvaged gear motor can shave a meaningful chunk off your total build cost.

⌨️ Cheat sheet

ROS2 commands you'll use constantly

CommandWhat it does
ros2 node listList all currently running nodes
ros2 topic listList all active topics
ros2 topic echo /scanPrint live messages published on a topic

ros2 run <pkg> <executable>Run a single node from a package

❓ FAQ

Frequently asked questions

Do I need prior robotics experience to start?+

No. You need basic comfort with Python and the command line. Modules 1–2 bring everyone up to speed on Linux, Git, and the math refresher before ROS2 begins in Module 3.

Can I complete the course without buying hardware?+

Yes — every concept has a browser-based interactive lab, and Gazebo simulation covers the same ROS2/Nav2 workflow. The DIY build (Modules 11–12) is where you apply it to real hardware, but it's not required to learn the material.

Which ROS2 distribution should I use?+

ROS2 Humble Hawksbill (LTS) on Ubuntu 22.04 — it's what all course examples, launch files, and the DIY build guide target.

What if my budget is tighter than ₹50,000?+

Skip the RPLidar and go camera + ultrasonic-only for roughly ₹20,600 — see the callout on the Bill of Materials section. You'll still cover differential drive, ROS2, and camera-based object detection; you can add LiDAR-based SLAM later.

Do I need a powerful GPU for the AI/object detection modules?+

No — Module 6 focuses on lightweight, edge-optimized detectors (MobileNet-SSD, small YOLO variants) that run in real time on a Raspberry Pi, optionally accelerated with a Coral USB TPU.

Is a Raspberry Pi 4 required, or can I use something else?+

A Raspberry Pi 4 (4GB) is the reference board for pricing and instructions, but any board that runs Ubuntu 22.04 and has enough GPIO/USB for your sensors (a Pi 5, a Jetson Nano, or similar SBC) will work with minor adjustments.
