Learn robotics concepts by playing with them

Lab 01 · Differential Drive Kinematics

Steer a robot and watch the math live

Set independent left/right wheel speeds and watch how the robot's linear velocity (v) and angular velocity (ω) fall out of the difference between them — the same math behind /odom.

Equal speeds → straight line. Opposite speeds → rotation in place. Different-magnitude same-sign speeds → an arc turn.

Lab 02 · PID Controller Playground

Tune Kp, Ki, Kd and watch the response curve

The controller is trying to drive a simulated motor to a target velocity (dashed line). Push the gains too far and you'll see overshoot and oscillation — exactly what you'll fight when tuning a real drivetrain.

Live simulation
Overshoot0.0%
Settling time0.00 s

Higher Kd damps oscillation but reacts to noise. Higher Ki removes steady-state error but can overshoot.

Lab 03 · Global Planner (A*)

Build a maze, then watch A* solve it

This is what a global planner does on a costmap: search the known grid for the shortest collision-free path from start (S) to goal (G). The violet cells are nodes the search explored; the teal cells are the final path.

Live simulation

Click cells to add walls, then Run A*.

Try walling off the goal completely — the planner will correctly report no path found.

Lab 04 · Local Planner & Obstacle Avoidance

React to obstacles the map didn't know about

The global planner gives a route across the map — but the local planner has to dodge things in real time. This robot casts simulated range-sensor rays and steers using a simple attractive/repulsive blend, similar in spirit to DWA.

Live simulation

Click the canvas to add/remove obstacles, then Run.

Click an existing obstacle to remove it. Up to 8 obstacles at once.

Lab 05 · Object Detection: IoU Playground

How detectors like YOLO get graded

Drag the orange prediction box (drag the body to move, the bottom-right corner to resize) and watch Intersection-over-Union update against the green ground-truth box. Adjust the threshold to see when a detection counts as a match.

Live simulation
IoU score0.00
Verdict—

IoU = overlap area ÷ combined area. A typical mAP@0.5 benchmark counts anything ≥ 0.5 as a true positive.
