🧪 8 simulators · most in interactive 3D

Learn robotics concepts by playing with them

These are simplified, teaching-scale simulations — not the real ROS2/Nav2 stack — built to give you fast, visual intuition for ideas that are usually only explained in equations. Drag to orbit each 3D scene, tap to interact, and break things freely.

Lab 01 · Differential Drive Kinematics

Steer a robot and watch the math live

Set independent left/right wheel speeds and watch how the robot's linear velocity (v) and angular velocity (ω) fall out of the difference between them — the same math behind /odom.

Equal speeds → straight line. Opposite speeds → rotation in place. Different-magnitude same-sign speeds → an arc turn.

Lab 02 · PID Controller Playground

Tune Kp, Ki, Kd and watch the response curve

The controller is trying to drive a simulated motor to a target velocity (dashed line). Push the gains too far and you'll see overshoot and oscillation — exactly what you'll fight when tuning a real drivetrain.

Higher Kd damps oscillation but reacts to noise. Higher Ki removes steady-state error but can overshoot.

Lab 03 · Global Planner (A*)

Build a maze, then watch A* solve it

This is what a global planner does on a costmap: search the known grid for the shortest collision-free path from start (S) to goal (G). Light-blue tiles are cells the search explored; blue tiles are the final path.

3DLive simulation
Drag to orbit · tap a tile to edit

Tap cells to add walls, then Run A*.

Try walling off the goal completely — the planner will correctly report no path found.

Lab 04 · Local Planner & Obstacle Avoidance

React to obstacles the map didn't know about

The global planner gives a route across the map — but the local planner has to dodge things in real time. This robot casts simulated range-sensor rays and steers using a simple attractive/repulsive blend, similar in spirit to DWA.

3DLive simulation
Drag to orbit · tap the floor to place

Tap the floor to add/remove obstacles, then Run.

Tap an existing obstacle to remove it. Up to 8 obstacles at once.

Lab 05 · Mapping (SLAM-style Occupancy Grid)

Watch the fog of war lift as the robot explores

Every cell starts unknown. As the robot wanders, it casts simulated LiDAR rays and reveals cells as free or occupied — the same idea behind slam_toolbox building a map from scratch. Sketch hidden walls first, then watch the robot uncover them.

3DLive simulation
Drag to orbit · tap fog to sketch walls
Map explored0%

Tap fogged cells to sketch hidden walls, then start exploring.

Gray = unknown, white = free, dark = wall. The robot only reveals what its sensors can actually see.

Lab 06 · Full Navigation (Global + Local Planner)

Plan a route, then hold it against a moving obstacle

This is Nav2 in miniature: A* plans a global path across the grid, the robot follows it, and a wandering obstacle forces the local planner to yield — and, if blocked too long, trigger a full replan. Draw walls, set a goal, and hit Navigate.

3DLive simulation
Drag to orbit · tap to draw walls / set goal

Draw walls or drag-orbit to inspect, set a goal, then Navigate.

The red sphere is a dynamic obstacle the map doesn't know about — watch the robot yield, then re-route around it.

Lab 07 · Object Detection: IoU Playground

How detectors like YOLO get graded

Drag the orange prediction box (drag the body to move, the bottom-right corner to resize) and watch Intersection-over-Union update against the green ground-truth box. Adjust the threshold to see when a detection counts as a match.

Live simulation
IoU score0.00
Verdict—

IoU = overlap area ÷ combined area. A typical mAP@0.5 benchmark counts anything ≥ 0.5 as a true positive.
